# Reproducibility and Data Availability

This file is the data-availability statement for the CodeAssay evaluation
reported in the PROFES 2026 paper. It records the execution environment, the
exact tool versions, the generation run settings, and a per-file inventory of
everything released.

Everything the paper reports is derived from the files listed here. The paper
itself states only the measures and the tools; the versions, the analyzer
configurations, and the file-by-file inventory live in this document.

Every value here is taken from what the run recorded (`.agent_runs/r2-*/runinfo.json`,
`reports/r2_generation_settings.md`) or from the interpreter the analysis ran in.

The analyzer versions matter. `radon`, `flake8`, `bandit`, `semgrep` and `mutmut`
determine the numeric values reported in the paper, so a rerun on different
versions may produce different counts from identical programs.

`requirements-lock.txt` predates this evaluation and disagrees with the versions
above on `openai`, `scipy` and `numpy`, and omits `anthropic`, `bandit`, `mutmut`
and `semgrep`. It should not be used as the environment record until it is
regenerated.

### Deterministic grading

Grading subprocesses run with `PYTHONHASHSEED=0`, so a solution that iterates a
set or dict emits in a fixed order. Set in `scripts/verify_and_repair_audit.py`
and `scripts/audit_effect.py`. All 2,590 stored programs were graded twice in
separate sessions with identical outcomes.

**Settings that were not sent.** No reasoning or effort parameter for
`gpt-5.6-sol`, no thinking or budget parameter for `claude-sonnet-5`, and no
provider-routing or reasoning field for Gemini through OpenRouter. All of these
ran at the provider default. GPT-5.6-sol did reason: the OpenAI usage records

The OpenRouter responses name Google as the serving provider on all 390 calls.

`gpt56sol-sec` carries a 900 s timeout because two attempts in that run raised
`APITimeoutError` at 60 s and were regenerated with the longer timeout. That is
the only setting differing from the other thirteen runs.

Per-configuration settings, API-call accounting, finish reasons and cost ledgers:
`reports/r2_generation_settings.md`, regenerated by
`scripts/r2_generation_settings.py`.

## Prompts

Both prompts are in the agent modules (`scripts/agents/openai_agent.py`,
`claude_agent.py`, `openrouter_agent.py`), byte-identical across the three.

The user message is identical under both conditions. The system message differs
in two ways: the security-focused variant inserts `security-conscious` into the
persona sentence, and appends one instruction.

Repair feedback is the combined pytest output from a run with `-x --maxfail=1`,
so only the first failing test is reported. It is reduced to the last 80 lines,
then to the last 1,200 characters of that text, and appended to the original
prompt.

regenerated from this repository alone.

## Reproducing the analysis

Regenerating model outputs will not reproduce ours. Two of the seven models do
not accept a temperature setting, and closed models can change behind a fixed
identifier. The stored outputs under `.agent_runs/r2-*/` allow the analysis to be
reproduced exactly.

```bash
python3.12 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python3 scripts/verify_and_repair_audit.py    # regrade the stored programs
python3 scripts/rev_stats_v2.py               # correctness and quality
python3 scripts/per_category_correctness.py   # per-category correctness
python3 scripts/leakage_check.py              # contamination audit
```

## What is not included, and why

- **Pre-revision results (May 2026).** An earlier evaluation covering 120 tasks
  and five models used a composite score and graded on tests the model had been
  shown. Those results are invalid. They are kept out of this repository rather
  than published alongside the corrected ones.
- **Manuscript sources and figure-generation code.** Out of scope for a
  replication package.
- **`.agent_runs/r2-*/cache/`**, apart from `cache/attempt1/`. The top-level
  cache files duplicate each run's own
  `tasks/python/<task>/src/solution.py` byte for byte, verified across all 2,590
  programs. `cache/attempt1/` is released because it holds the pre-repair
  programs, which exist nowhere else and are the evidence behind
  `reports/r2_repair_audit.csv`.
- **The superseded run directories** under `.agent_runs/` that carry no `r2-`
  prefix.

## Known gaps

- `requirements-lock.txt` disagrees with the versions above on `openai`, `scipy`
  and `numpy`, and omits `anthropic`, `bandit`, `mutmut` and `semgrep`. Use the
  table in this document as the environment record until the lock file is
  regenerated.
- Two of the seven models do not expose a temperature setting, so decoding is
  not uniform across all seven. The output limit and token budget are.
- Equivalent mutants were not identified, so both mutation scores are lower
  bounds.
